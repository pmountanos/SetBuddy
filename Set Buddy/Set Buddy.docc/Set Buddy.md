## Overview

Set Buddy is a local-first iOS app for workout programs, scheduling, and logging. The **Today** tab reflects workout, rest, and in-progress state (**Start** vs **Continue**). The workout screen shows the **last session’s** weight and reps as **reference** (orange-filled fields); after you **commit** a set, fields switch to **entered** styling—**only committed** sets are kept when you **Finish**. **Settings** can **export** the active program and full workout history as **`.xlsx`** (with **`.csv`** fallback) for sharing or backup.
